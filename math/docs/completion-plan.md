# 需求对照与交付范围

以 NaturplayCalculator.Core 的 FunctionCatalog、NumericDomain、Combinatorics、Statistics 和矩阵操作为需求来源。目标是完成独立计算库；主程序界面和旧计算引擎的接入不属于此次改造。

| 需求 | 实现与验收 |
| --- | --- |
| 精确输入与中间结果 | BigInteger、Rational、不可变表达式；有限小数和科学计数法精确解析；显示结果不回流成输入 |
| 任意精度初等求值 | 四则、一般幂／根、ln/exp、三角／反三角、双曲／反双曲的认证区间；百万位实际计算见 verification.md |
| 符号化简 | 常量、同类项／幂、根式、常见三角特值、sin²+cos²、ln/exp；同时保留定义域 |
| 计算器语法 | 括号、隐式乘法、右结合幂、阶乘／双阶乘、组合／排列、mod、角度模式及函数别名 |
| 任意进制 | BigInteger 进制；2–36 普通数码，更大进制用括号数码；分治转换；任意更换输出格式 |
| 异步与取消 | CalculateAsync、CalculateComplexAsync、实／复／矩阵 ApproximateAsync；链接令牌、变量快照、独立调用会话 |
| 更新进度 | 一个任务 ID；阶段、局部实际工作量、工作精度、检查点与耗时；最终文本认证后才发 Completed |
| 复数 | 精确笛卡尔表达式、主值函数、i、conj/re/im/arg、复数幂、零底数与分支测试 |
| 矩阵 | 精确加／乘／幂、转置、共轭转置、无除法行列式、逆、精确或认证秩；API 构造，不新增矩阵文本语法 |
| 统计 | 总体均值、方差、协方差、相关系数；保持应用非共轭复矩约定；巨大偏移测试 |
| 无损保存 | 实／复表达式、条件、矩阵、实区间的版本化 JSON；重建内在定义域 |
| 性能与独立校验 | 千位到百万位阶梯实测；记录耗时、内存、程序集 SHA256；MPFR 双向舍入逐位比对 |

库没有浮点数值通道、自定义数串算术或全局可变精度。数学整数和进制使用 BigInteger；显示位数、索引和资源策略仍使用运行时机器类型。

“任意初等形式”指可组合支持的初等运算，并对已认证的结果提供任意请求精度；不等于完整 CAS 或对任意等式、分支、奇点都保证有限时间判定。资源不足或条件无法证明时返回明确异常。非初等特殊函数、符号积分和任意方程求解不在此目标内。
